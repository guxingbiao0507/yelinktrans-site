- 上线包：V1.0

## 已包含能力

- 中英文独立SEO标题和描述；
- Canonical、hreflang、Sitemap和robots；
- 中英文语言切换；
- 响应式桌面、笔记本、平板和手机布局；
- 自定义404页面；
- 中文和英文社交分享图；
- SVG及PNG网站图标、Apple Touch图标；
- Microsoft 365邮箱链接；
- 静态输出和可维护的Nuxt源代码；
- 通用静态托管、Git自动构建和Nginx部署说明。

## 明确延期的能力

- 后台内容管理、登录和权限；
- 数据库和服务器运行时；
- 在线留言表单；
- 网站分析、广告追踪和营销Cookie；
- 阿拉伯文化风险审核方案；
- 正式品牌Logo设计。

当前继续使用已确认的YELINKTRANS文字标识，不影响首版上线。

## 当前仍由部署人员确认

- 最终托管平台；
- 服务器或节点地区；
- 是否使用中国大陆服务器及ICP备案；
- 正式DNS记录值和HTTPS证书方式。

这些信息无法在服务器平台确定前预填，上线包已提供平台无关的部署方案和核验清单。

## 质量门槛

交付前必须通过：

- Nuxt TypeScript类型检查；
- 正式静态生成；
- 10条中英文路由检查；
- 内部链接、Canonical、hreflang、Sitemap和robots检查；
- 宣传数据和案例归属检查；
- 英文特定换行结构检查；
- 静态文件秘密信息扫描；
- 压缩包完整性和SHA-256校验。
